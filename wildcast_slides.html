Compliance
How we stay GDPR compliant
📄

Text-only API calls

No partner images are ever sent to the Claude API. The corpus is a plain .txt file — no personal data, no images.

✍️

DPA required

A Data Processing Agreement must be signed with Wolt before any partner data flows through the system.

🗑

No data retention

Partner content is processed at export and discarded. Nothing is stored server-side after the PDF is delivered.

🔐

Scoped Drive access

Google Drive OAuth scoped to drive.file only. Write to partner folder — nothing else is readable.

Pre-Build
What to audit before we build
✓

Layer naming

Fields named for use: headline, offer_text, product_image — not Figma jargon

✓

Bleed setup

3mm bleed on all sides, crop marks placed outside the bleed area

✓

Field count

4–6 editable fields per template — test with non-designers before build

✓

Image placeholders

Aspect ratio locked. Min 150dpi warning, blocks below 72dpi

✓

Character limits

Define max chars per text field based on bounding box dimensions + print size

✓

ICC profile confirmed

Confirm Wolt printer ICC profile — likely ISOcoated_v2_300 for EU print
